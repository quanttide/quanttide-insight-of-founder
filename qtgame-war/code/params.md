# 参数

一句话：数值不进代码，准不准靠区间与敏感性兜底。

新增数值一律进参数表并记指纹，代码里出现裸数值即违例；否则每次分布漂移都无法归因到改了哪里。历史参数不求点值，用区间、来源性质、三视角交集交付，由敏感性分析兜底——只要历史结果在参数带内能涌现，绝对精度就不重要。
