# 复盘与档案

一句话：一局打完，事件、报告、拒绝、增量都留下，复盘才不是猜。

事件与报告在关卡处分开，上层只读报告，迷雾才有可测量的对照面。命令失效不能静默丢弃，预检失败与结算拒收都要生成事件；结算只交增量补丁，由世界状态合并写入，才能回答「这一次结算改了什么」。

## 假说

- **档案是迷雾可被测量的前提**：事件与报告在关卡处分开，上层只读报告；没有这层隔离，复盘无从对照，也判断不了迷雾有没有生效。出处：四份游戏路线图稿件对齐时的判断（2026-10-25）。
- **命令失效必须留档**：预检失败与结算拒收都生成事件，不静默丢弃；否则复盘时「我下了命令，为什么没执行」无从解释。出处：《架构设计说明书 v1.1》评审 §3.4。
- **结算只交增量补丁**：各阶段结算返回变更、由世界状态合并写入，与事件流同构；整树快照会让「这次结算改了什么」重新变成猜。出处：《架构设计说明书 v1.1》评审 §2.2。
