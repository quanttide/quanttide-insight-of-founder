# 语言

## 1. 背景与问题

同一批词，在财务报表里合格，在小说里就成了借来的比喻。前两轮按「这个词不好」删，越删越依赖逐句判断：同一个词换个文件又要重判一次，规则落不下来。

## 2. 判断

这类错不在词，在选词时看错了语境。词属于哪个领域，文档属于哪个领域，两个归属对上，词就是本职；对不上，才是借词。

## 3. 机制

词义由领域给，不靠词形。读者带着该领域的常识来读，词一换领域就得先翻译一次。把归属写成两处可读的东西——契约里标词属于哪个领域，文档头声明自己是哪个领域——外层规则就能机判，不必每次回到作者的口味。

## 4. 边界

这条只管专用词跨领域当比喻用的情况。词本身该不该存在，是另一个问题：正常中文用法占多数的词，硬换反而别扭，该讨论出库。

声明只放行它自己那个领域，别的领域照报；声明写的也是文档主题，不是文里出现过某个名词就算。

10-25 支付工程的文档声明 `finance` 后，闸门不再误拦其中的财务词；同一份词表在小说与报告里仍照报，未出现漏放。

## 5. 结论

判断一个词用得对不对，先问两句：它属于哪个领域，这份文档属于哪个领域。两个归属写在文件里，判断就能交给机器。
